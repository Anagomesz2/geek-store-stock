# 👾 Geek Store Stock (Warehouse Management)

Sistema de controle de estoque e precificação automatizada para loja de artigos colecionáveis e cultura pop.

## 📌 Escopo do Projeto
- **Cliente:** Júnior (Geek Store)
- **Interface:** Dashboard Web moderno.
- **Regras de Negócio:**
  - Cadastro categorizado de produtos (Action Figures, Hot Toys, Mangás).
  - Alerta visual para itens com estoque baixo (Low Stock < 3 unidades).
  - Cálculo automático de margem de lucro com base no Preço de Custo e Preço de Venda.

## 🛠️ Tecnologias e Infraestrutura
- Node.js / React.js
- PostgreSQL (Docker / Cloud)
